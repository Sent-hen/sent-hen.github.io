{%- comment -%} Item title: original language first, then English, e.g. "Le Festin · The Feast". With phonetic=true (not used on the site right now; /stuff/ shows the phonetic on its own line) a phonetic spelling follows: "Le Festin · The Feast · luh fess-TAN". Usage: {% include item-title.html item=it %} or {% include item-title.html item=it phonetic=true %}. Front matter: `original` (only when it differs from the English `title`) and `phonetic`. {%- endcomment -%} {%- assign i = include.item -%} {%- if i.original and i.original != i.title -%}{{ i.original }} · {% endif -%} {{ i.title }} {%- if include.phonetic and i.phonetic %} · {{ i.phonetic }}{% endif -%}
